# Basctdelm street props

These 1K glTF models are from [Poly Haven](https://polyhaven.com/), released under [CC0](https://polyhaven.com/license). `js/basctdelm-life.js` loads them as thin instances for the barrels, crates, buckets and baskets placed along Basctdelm's streets, stalls, piers and carts. Every file was verified against the MD5 checksums from Poly Haven's `/files/{asset}` API when it was downloaded (2026-09-26).

| Folder | Source |
| --- | --- |
| `wine_barrel_01/` | https://polyhaven.com/a/wine_barrel_01 |
| `wooden_crate_01/` | https://polyhaven.com/a/wooden_crate_01 |
| `wooden_bucket_01/` | https://polyhaven.com/a/wooden_bucket_01 |
| `wicker_basket_01/` | https://polyhaven.com/a/wicker_basket_01 |

The hand carts and townsfolk are procedural geometry built in `js/basctdelm-life.js`.
